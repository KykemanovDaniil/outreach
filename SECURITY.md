# Security Policy

## Supported Versions

As the project is in active development, security updates and critical stability patches are provided for the latest release branch only.


| Version         | Supported          |
| --------------- | ------------------ |
| Current (1.x.x) | :white_check_mark: |
| < 1.0.0         | :x:                |

## Reporting a Vulnerability

Even in a single-player game, the integrity of your system and save data is important. If you discover a critical bug that causes system instability, data loss, or potential security risks, please follow these steps:

### How to Report
1. **Private Reporting:** If you find a high-risk vulnerability, please do not open a public Issue. Instead, contact the maintainer directly through the contact methods listed on the [profile page](https://github.com/KykemanovDaniil).
2. **Public Issues:** For general bugs that do not pose a security risk (e.g., gameplay glitches), feel free to open a [GitHub Issue](https://github.com/outreach/issues).

### What to Include
Please provide a clear description of the issue, steps to reproduce it, and your system specifications (OS, Hardware). This helps in releasing a patch faster.

### Response Time
- **Acknowledgment:** You will receive a response within 48-72 hours.
- **Resolution:** Critical fixes will be prioritized and released as a patch (e.g., `1.0.x`) or a minor update (`1.x.0`).

Thank you for helping to keep Outreach stable and secure!
